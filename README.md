# local-ai

Squeezing local LLM inference out of weak hardware (GTX 1650 SUPER 4 GB + i5-10400F + 16 GB DDR4), on a patched PrismML llama.cpp fork.

- `notes.md` — the state file: hardware, findings, measurement tables, runbook. Start here.
- `bench/LEDGER.md` — every run with tok/s, VRAM, GPU util, wattage, PCIe, CPU, DRAM, expert-cache stats, quality and the commit that produced it (generated by `bench/ledger2md.py`).
- `bench/` — harness (`box/` mirrors `/ai/bench` on the box), quality eval (`qual/`), ledger tooling.
- `research/` — scout reports, upstream diffs and our patch series (`patches/box-series/` = `git format-patch` of the box branches on top of prism@9a9394a).
