# p4c1 — Prompt warm-up of the expert cache (P4c), N2-lite, V1 VRAM diet

Warming the expert cache during prompt processing removes the cold-miss uploads from decoded tokens (P4c); capping n-gram drafts at the GDN rollback depth avoids checkpoint+replay (N2-lite); keeping only head experts resident frees VRAM at a modest slot cost (V1). Each comparison below should move decode tok/s above the repeat-spread noise floor if the mechanism pays on this box.
